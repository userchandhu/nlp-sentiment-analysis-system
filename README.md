# NLP Sentiment Analysis System

## Project Overview
This project focuses on classifying text sentiment into positive and negative categories using NLP and Machine Learning techniques.
The project involved extensive debugging and preprocessing optimization to improve model performance.

## Problem Statement
Analyze customer or user sentiment from text data.

## Technologies Used
- Python
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression
- Multinomial Naive Bayes

## NLP Techniques Used
- Tokenization
- Stopword Removal
- Text Cleaning
- TF-IDF Vectorization
- N-Grams
- Sentiment Classification
